# Clinical Toolkit (Paediatrics)

An installable web app (PWA) for paediatric doctors: weight-based paediatric dose finder (30 medicines), neonatal jaundice thresholds (NICE CG98), neonatal fluids, paediatric DKA (BSPED 2021), resuscitation doses by weight (RCUK/ERC 2021), IMNCI danger signs, Nepal immunisation schedule, milestones, lab reference ranges, adult calculators, a drug reference, and optional AI tools (differential diagnosis, ECG and lab-report photo reading, drug monographs, interactions).

**Install on a phone:** open the site in Chrome (Android) and tap *Install app*, or in Safari (iPhone) tap *Share → Add to Home Screen*. It works offline after the first visit.

**AI features** need an Anthropic API key, entered in Settings. The key is stored only on the device and is never committed to this repository.

Decision support only. Verify doses against BNF for Children, the WHO Pocket Book, the Nepal National Formulary or your hospital protocol. Every built-in value lists its source in the app (Sources page).
